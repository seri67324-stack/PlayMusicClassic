# Play Music Classic

Kotlin + Jetpack Compose + Media3 ExoPlayer + Room (paket: com.playmusic.classic)

## APK alma
**Android Studio:** Klasörü aç → Gradle sync → Build > Build APK(s).
Gradle wrapper dosyaları (gradlew) pakette yok; Android Studio otomatik halleder.

**GitHub Actions:** Klasörü bir GitHub deposuna yükle → Actions sekmesi → "Build APK" → çıktı: PlayMusicClassic-debug-apk.

Gereksinimler: JDK 17, Gradle 8.5, AGP 8.2.2, Kotlin 1.9.22.
